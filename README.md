<h1 data-start="179" data-end="209">🕹️ Sega Arcade XML Splitter</h1>
<h2 data-start="211" data-end="228">🎯 Description</h2>
<p data-start="230" data-end="619">Ce script Python (<code data-start="248" data-end="275">Extract_Multi-SEGA.py</code>) permet d’analyser un <strong data-start="298" data-end="326">fichier XML de type MAME</strong> (ou équivalent) et d’en extraire automatiquement toutes les entrées liées au matériel <strong data-start="413" data-end="421">SEGA</strong>.<br data-start="422" data-end="425">
Il trie et classe les balises <code data-start="455" data-end="466">&lt;machine&gt;</code> ou <code data-start="470" data-end="478">&lt;game&gt;</code> selon le champ <code data-start="494" data-end="520">sourcefile="sega/...cpp"</code> et leur rattachement (<code data-start="543" data-end="550">romof</code>, <code data-start="552" data-end="561">cloneof</code>) dans des fichiers XML indépendants, un par système SEGA.</p>
<p data-start="621" data-end="752">Le but : <strong data-start="630" data-end="663">rendre lisible et exploitable</strong> les configurations des systèmes d’arcade SEGA sans modifier le fichier source d’origine.</p>
